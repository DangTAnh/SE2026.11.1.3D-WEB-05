# Security Policy

## Supported versions

This is a client-side educational project. Only the current `main` branch is
supported with security updates.

## Scope

In scope: the built web application, its preset parser, and the GitHub Actions
workflows in this repository.

Out of scope: third-party browser or GPU driver vulnerabilities, and deployments
that modify the source without review.

## Reporting a vulnerability

Do not open a public Issue. Use GitHub private vulnerability reporting:

https://github.com/DangTAnh/SE2026.11.1.3D-WEB-05/security/advisories/new

Include the affected revision, reproduction steps, impact, and any relevant
console output. We aim to acknowledge a report within seven days. Please do not
include credentials, personal data, or exploit details in public channels.
