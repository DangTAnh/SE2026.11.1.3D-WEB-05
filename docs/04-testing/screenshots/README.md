# Ảnh minh chứng UI tuần 1 — TV4

- `desktop-1440x1000.png`: giao diện desktop hai cột tại viewport 1440 × 1000.
- `mobile-500x844.png`: giao diện mobile một cột tại viewport 500 × 844.
